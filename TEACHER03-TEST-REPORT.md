# Teacher Mode 0.3 — локальная проверка

Дата: 12 ноября 2026. Прототип изолирован от стабильной папки.

- Все 372 автотеста прошли, включая проверку общего локального адреса для панели, уроков и STT.
- `npm run build:pages` и `npm run build:backend`: успешно. Публичный адрес сервиса уроков пока не указан; для публикации нужен `TEACHER_API_BASE_URL`.
- `npm run dev` запускает игру и сервис уроков на 5175. На этом адресе панель и диагностика уроков вернули HTTP 200. В двух изолированных контекстах Chrome проверены создание урока, подключение по ссылке, создание кровати, блокировка и повтор просмотра фильма, завершение урока.
- Запрос через локальный `/api/stt` передал тестовую запись в Groq и вернул `침대` с HTTP 200. Для проверки использована конфигурация из соседней папки игры. Запрос к `/.env` вернул HTTP 404.
- Два изолированных браузерных контекста Chrome: соединение по ссылке, создание кровати, блокировка фильма без телевизора, явное создание телевизора и повтор, ручное исправление `연화를 봐요`, отсутствие повторного действия после позднего `영화를 봐요`, работоспособность пульта после ошибки STT, обновление страницы без повторов, «Повтори», возврат к уровню 1 и возраст 10, отзыв доступа при завершении урока.
- Для браузерного теста STT использованы искусственные сетевые ответы и аудиозаглушка. Внешние STT API и реальные записи в этом прогоне не использовались. Игровой движок, интерпретатор, HTTP-сервис уроков и подтверждения выполнялись реально.
- На 1366×768 при масштабе 100% основные действия помещаются без прокрутки (нижняя граница действий около 600 px). [Снимок](docs/teacher03-dashboard-1366.png).
- Контрольные суммы исходных файлов стабильного проекта совпадают с исходным снимком. Его архив не заменялся. Секретные файлы в пакет не включены.

Не проверено: два физических устройства, публичный сервис уроков, маршрут Корея → Россия без VPN. Это обязательный следующий этап после отдельной публикации; локальный результат его не заменяет. Комнаты хранятся в памяти, перезапуск сервиса завершает их. При обновлении страницы посреди действия подтверждение может остаться неизвестным, повторного выполнения не происходит.
