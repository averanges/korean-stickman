# Teacher Mode 0.3

Публичный интерфейс находится на GitHub Pages, а Render обслуживает STT и временные учебные комнаты в одном процессе. [Пульт преподавателя](https://averanges.github.io/korean-stickman/teacher.html)

## Локально

Откройте терминал **в этой папке** с Node.js 24.

```powershell
npm run dev
```

Эта команда запускает игру и сервис уроков на порту 5175. Для живого STT можно указать `GROQ_API_KEY` в локальном `.env` прототипа. Если ключ уже настроен в соседней папке `korean-stickman`, вместо предыдущей команды можно запустить:

```powershell
npm run dev:existing-stt
```

Пульт: `http://localhost:5175/teacher.html`. Нажмите «Создать урок», затем «Ссылка ученика». Откройте ссылку в другом браузере. Для подключения нужна именно ссылка ученика. Для теста на одном компьютере можно использовать отдельную вкладку; второй экземпляр уже подключённого ученика не должен перехватывать урок.

Игра: `http://localhost:5175/`. Диагностика уроков: `http://localhost:5175/teacher-api/health`. Сохранения привязаны к адресу браузера и не переносятся между портами автоматически.

Если процесс перезапустился, создайте новый урок и возьмите новую ссылку. Сервис уроков хранит комнаты в памяти. Для публичной версии используйте отдельный сервис через `npm run teacher:server`.

## Что проверить

Пульт автоматически следует за уровнем ученика. На первом уровне доступны прежние характеристики, возраст и семья. На втором — существующие предметы и игровые действия. Предмет добавляется кнопкой `+`, удаляется отдельной `−`. Сейчас движок поддерживает по одному экземпляру каждого предмета; пульт показывает фактические количества.

Без телевизора просмотр фильма блокируется. Нажмите `+ 텔레비전`, дождитесь подтверждения, затем «Повторить действие». Преподавательские команды используют ту же очередь, размещение и навигацию, что обычные команды. «Выполнено» появляется после завершения операции движка.

Флажок «Исправить эту попытку» привязывает действие к последнему голосовому запросу и подавляет его запоздалый ответ. Снимите флажок для независимой команды. Уже выполняющееся голосовое действие не прерывается исправлением; новая независимая операция встаёт в очередь. Неопределённая речь включает размышление, окончание ожидания возвращает героя в нейтральное состояние. Ошибка сети не означает неправильную речь.

«Диагностика и журнал» содержит технические события и подтверждения. При обновлении ученика восстанавливаются временный доступ, текущий уровень и сохранённый мир; завершённые команды не повторяются. Если обновление произошло во время действия, результат может остаться неизвестным — автоматического повтора нет.

## Публикация и откат

Render использует текущую команду запуска Node.js. `RENDER=true` включает API уроков на `/teacher-api/`. `/health` по-прежнему показывает состояние STT. Сервису нужен один экземпляр Node.js, поскольку комнаты находятся в памяти процесса. Перезапуск Render завершает активные уроки.

В GitHub Settings → Pages выберите GitHub Actions. В Actions запустите `Publish frontend to GitHub Pages` с ветки `main`. Workflow проверит `/teacher-api/health` и соберёт статический интерфейс. Адрес уроков берётся из `TEACHER_API_BASE_URL` и по умолчанию равен `https://korean-stickman.onrender.com`.

Для отката **фронтенда** запустите тот же workflow на `main` с флажком `rollback`. Он соберёт версию из тега `production-before-teacher-mode-03` (коммит `c5c34d15736b84097c73acfe5e106bbdd0ddc0e1`). Через CLI:

```sh
gh workflow run pages.yml -R averanges/korean-stickman --ref main -f rollback=true
```

Для отката **сервера** откройте существующий сервис `korean-stickman` на Render, перейдите в Deploys, найдите последний успешный деплой до выпуска Teacher Mode 0.3 и выберите **Rollback**. Если артефакт недоступен, выберите **Manual Deploy → Deploy a specific commit** и укажите SHA этого предыдущего деплоя. После отката проверьте `/health` и пробное распознавание на сайте. При откате обоих компонентов сначала верните фронтенд, затем сервер. Откат Render через Dashboard выключает автодеплой. [Документация Render](https://render.com/docs/rollbacks)

Ссылку доступа преподавателя храните отдельно от приглашения ученика. Урок действует час. Кнопка «Завершить урок» отзывает оба доступа.
