# Teacher Mode 0.3 — отдельный прототип

Эта папка предназначена для отдельного тестирования. Не заменяйте ею текущий Korean Stickman до проверки на двух устройствах. Публичный сервис уроков ещё не настроен. Стабильная игра находится в соседней папке `korean-stickman`.

## Локально

Откройте терминал **в этой папке** с Node.js 24.

```powershell
npm run dev
```

Эта команда запускает игру и сервис уроков на порту 5175. Для живого STT можно указать `GROQ_API_KEY` в локальном `.env` прототипа. Если ключ уже настроен в соседней папке `korean-stickman`, вместо предыдущей команды можно запустить:

```powershell
npm run dev:existing-stt
```

Пульт: `http://localhost:5175/teacher.html`. Нажмите «Создать урок», затем «Ссылка ученика». Откройте ссылку в другом браузере. Для подключения нужна именно ссылка ученика. Для теста на одном компьютере можно использовать отдельную вкладку; второй экземпляр уже подключённого ученика не должен перехватывать урок.

Игра: `http://localhost:5175/`. Диагностика уроков: `http://localhost:5175/teacher-api/health`. Сохранения привязаны к адресу браузера и не переносятся между портами автоматически.

Если процесс перезапустился, создайте новый урок и возьмите новую ссылку. Сервис уроков хранит комнаты в памяти. Для публичной версии используйте отдельный сервис через `npm run teacher:server`.

## Что проверить

Пульт автоматически следует за уровнем ученика. На первом уровне доступны прежние характеристики, возраст и семья. На втором — существующие предметы и игровые действия. Предмет добавляется кнопкой `+`, удаляется отдельной `−`. Сейчас движок поддерживает по одному экземпляру каждого предмета; пульт показывает фактические количества.

Без телевизора просмотр фильма блокируется. Нажмите `+ 텔레비전`, дождитесь подтверждения, затем «Повторить действие». Преподавательские команды используют ту же очередь, размещение и навигацию, что обычные команды. «Выполнено» появляется после завершения операции движка.

Флажок «Исправить эту попытку» привязывает действие к последнему голосовому запросу и подавляет его запоздалый ответ. Снимите флажок для независимой команды. Уже выполняющееся голосовое действие не прерывается исправлением; новая независимая операция встаёт в очередь. Неопределённая речь включает размышление, окончание ожидания возвращает героя в нейтральное состояние. Ошибка сети не означает неправильную речь.

«Диагностика и журнал» содержит технические события и подтверждения. При обновлении ученика восстанавливаются временный доступ, текущий уровень и сохранённый мир; завершённые команды не повторяются. Если обновление произошло во время действия, результат может остаться неизвестным — автоматического повтора нет.

## Отдельная публикация

Для одной ссылки на игру, пульт и уроки создайте отдельный Node.js Web Service на ветке `teacher-mode-03`. Для Render укажите сборку `npm ci`, запуск `npm run start:teacher-preview` и проверку `/teacher-api/health`. На Render приложение использует HTTPS-адрес из `RENDER_EXTERNAL_URL` и порт из `PORT`. Для другого хостинга или временного HTTPS-туннеля задайте `PUBLIC_ORIGIN` с точным внешним HTTPS-адресом. Для голоса задайте `GROQ_API_KEY` на стороне сервера. Открывайте `/teacher.html` по этому адресу. Сервису нужен один экземпляр Node.js. Комнаты хранятся в его памяти.

Ниже описан вариант с отдельным GitHub Pages для интерфейса и сервисом уроков.

1. Создайте **новый** репозиторий, например `korean-stickman-teacher03-preview`, и загрузите содержимое этой папки. Не заменяйте основной репозиторий или работающие STT-сервисы.
2. Создайте отдельный постоянно работающий Node.js 24 сервис уроков из этого репозитория: установка `npm ci`, запуск `npm run teacher:server`. Он использует `PORT` платформы и слушает `0.0.0.0`. Установите `NODE_ENV=production`, `FRONTEND_ORIGINS=https://averanges.github.io` (только origin, без пути). Если другой GitHub-владелец, укажите его точный origin. HTTPS обязателен. Не используйте несколько экземпляров сервиса: комнаты хранятся только в памяти одного процесса; перезапуск удаляет уроки.
3. Убедитесь, что публичный `/health` возвращает `service: teacher-mode`, `version: 0.3.0`. Адрес STT не заменяет адрес сервиса уроков.
4. В новом GitHub-репозитории добавьте **Actions variable** `TEACHER_API_BASE_URL` с HTTPS-адресом этого сервиса без пути. Это публичный адрес, не секрет. Остальные переменные STT уже имеют прежние значения по умолчанию; новые API-ключи не нужны.
5. В Settings → Pages выберите GitHub Actions. Запустите workflow `Teacher Mode 0.3 preview only` вручную. Он разрешён только для репозиториев с окончанием `-teacher03-preview` и требует непустой `TEACHER_API_BASE_URL`. Это защита от случайной замены стабильных Pages.
6. Откройте новый адрес `/korean-stickman-teacher03-preview/teacher.html`, создайте **новый** урок и отправьте его ссылку ученику. Локальные уроки и ссылки не переносятся в публичный сервис.

Для ручной сборки: задайте `API_BASE_URL=https://korean-stickman.onrender.com` и `TEACHER_API_BASE_URL=https://ВАШ-СЕРВИС-УРОКОВ`, выполните `npm run build:pages`. Публикуется только содержимое `dist`, а не исходники и `.env`. Пути относительные, поддерживается размещение в подпапке.

Не включайте на хостинге журналирование Authorization, тел запросов и ссылок доступа. Приглашение передаётся во фрагменте URL и удаляется из строки адреса после чтения. Доступ преподавателя храните отдельно от ссылки ученика. TTL урока — час; завершение отзывает оба доступа. История не сохраняется постоянно, аудио не передаётся в сервис уроков.

## Границы проверки

Автотесты и два изолированных браузерных контекста на одном компьютере проверяют локальную доставку и игровые подтверждения. Это **не** подтверждает доступность из России. После отдельной публикации нужны учитель в Корее и ученик в России без VPN: создание предмета, исправление STT, отсутствие телевизора и повтор, отказ STT при рабочем пульте, обновление страницы без дублей, поздний STT и реакция «Повтори». До этого стабильную версию не заменять.

Результаты локальной проверки: [TEACHER03-TEST-REPORT.md](TEACHER03-TEST-REPORT.md).
