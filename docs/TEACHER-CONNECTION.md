# Подключение после обновления игры

На работающем localhost:8081 подтверждён сервис комнат версии **0.1.0**. Тестовая комната создаётся (201), ученик принимается (200), но текущее состояние игры отклоняется с **400 invalid-data**. Состояние старого формата принимается (200). Проверочная комната закрыта; пользовательские комнаты не менялись.

Причина — старый процесс Node.js продолжает выполнять код, загруженный до обновления файлов. Обновление страницы или новая ссылка не обновляют этот процесс. Текущий исходник сервиса — **0.2.1** с поддержкой возраста, семьи и статуса попытки. Это отдельный сервис от STT.

## Как восстановить связь

1. В терминале, где написано `Teacher service listening on port 8081`, нажмите **Ctrl+C**.
2. Из обновлённой папки проекта запустите `npm run teacher:server`.
3. Откройте `http://localhost:8081/health`: ожидается `version: 0.2.1`.
4. Обновите панель преподавателя и игру через **Ctrl+F5**.
5. Создайте новый урок и откройте новую ссылку ученика. Перезапуск удаляет временные комнаты, поэтому прежние ссылки уже не подходят.

Игра на 5173 и серверы STT менять не требуется. Прогресс героя хранится отдельно и не сбрасывается.

В клиенте вместо общего «Не удалось связаться с уроком» теперь есть пояснение для `invalid-data` и `invalid-command`. Проверки полей на сервере сохранены; новый профиль не отправляется в старом формате с потерей возраста и семьи.
