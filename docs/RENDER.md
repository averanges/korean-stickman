# Публикация на одном Render Web Service (Free)

Проект подготовлен, но сервис и GitHub-репозиторий автоматически не создавались.

## GitHub

Загружайте содержимое текущей папки `korean-stickman` как корень отдельного репозитория.
Не загружайте всю папку `outputs` с архивными копиями.
`.env` должен оставаться только на компьютере. Для образца в репозитории есть пустой `.env.example`.
Если секрет когда-либо уже попал в историю Git, одного `.gitignore` недостаточно: ключ нужно заменить.

## Render

- Type: Web Service.
- Runtime: Node.
- Instance: Free.
- Root Directory: пусто, если содержимое проекта находится в корне репозитория.
- Build Command: `npm ci`.
- Start Command: `npm start`.
- Health Check Path: `/api/stt/status`.

Переменные:

| Имя | Значение |
|---|---|
| `GROQ_API_KEY` | Ваш ключ, обязательно; задайте как секрет в Render |
| `STT_MODEL` | Необязательно: `whisper-large-v3` по умолчанию |
| `PUBLIC_ORIGIN` | Необязательно для стандартного onrender.com; для своего домена: `https://ваш-домен` без пути |

`RENDER`, `PORT` и `RENDER_EXTERNAL_URL` предоставляет Render автоматически.
На Render приложение слушает `0.0.0.0` и выделенный `PORT`; локально — `127.0.0.1:5173`.
Локальный `.env` на Render не читается. В стандартном случае домен берётся из `RENDER_EXTERNAL_URL`.
При `PUBLIC_ORIGIN` разрешается только этот публичный домен; дополнительные домены не открываются автоматически.

## Ограничения STT

- Максимум 2 одновременные операции загрузки/распознавания на экземпляр сервера.
- Максимум 20 начатых операций в скользящие 60 секунд суммарно для всех пользователей экземпляра.
- Максимальный аудиофайл: 20 МиБ.
- При превышении частоты/параллельности: HTTP 429 и существующее сообщение о повторной попытке.
- При превышении размера: HTTP 413. Отказ до обращения к Groq.

Лимиты хранятся в памяти и сбрасываются при перезапуске/пробуждении экземпляра.
Они ограничивают случайную нагрузку, но не являются авторизацией и не гарантируют денежный лимит аккаунта Groq.
На Free нет отдельного постоянного хранилища или фоновых задач. Heartbeat не добавлен.

## Проверки

`npm test` проверяет локальные обращения, публичный Host + HTTPS Origin как за TLS-прокси Render,
отказ для посторонних доменов, выдачу всех игровых JS/CSS/SVG, недоступность секретов,
лимиты параллельности/частоты/размера, возврат занятого слота при ошибках и все прежние игровые тесты.
Это локальная имитация публичных HTTP-заголовков, а не проверка уже опубликованного домена.
После самостоятельного деплоя проверьте реальный HTTPS-адрес, разрешение микрофона и одну фразу.
Прогресс localhost не переносится на публичный домен автоматически: хранилище браузера раздельное.

Справка: https://render.com/docs/web-services и https://render.com/docs/environment-variables.
