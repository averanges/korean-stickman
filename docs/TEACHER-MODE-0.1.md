# Teacher Mode 0.1 — первый уровень

Первичная настройка сохранена для справки. Текущий пульт: [Teacher Mode 0.2](TEACHER-MODE-0.2.md).

Подготовлен локальный прототип. Публикация не выполнялась. Обязательная приёмка в двух браузерах/на двух устройствах ещё не завершена.

## Как пользоваться

1. Откройте `teacher.html` через ссылку **Teacher Mode** в шапке игры.
2. Нажмите **Создать урок** → **Скопировать ссылку ученика**. Отправьте ссылку ученику самостоятельно, например через Telegram.
3. **Скопировать мой доступ** сохраняет отдельную защищённую ссылку преподавателя. Её нельзя отправлять ученику.
4. Ученик открывает свою ссылку: подключение происходит автоматически, без кода и формы. Пригласительный токен удаляется из адресной строки, рабочий доступ остаётся во временном хранилище вкладки.
5. После подключения кнопками можно выбрать национальность, профессию, пол и приветствие. Варианты берутся из действующего каталога первого уровня.
6. Следите за статусом каждой команды. **Отправлено** и **Получено учеником** ещё не означают выполнение. **Выполнено** означает, что существующий игровой движок завершил действие.
7. Если вручную исправляете голосовую попытку, сначала включите флажок **Эта команда исправляет последнюю голосовую попытку**, затем отправьте характеристику. Связанный поздний STT-ответ не должен перезаписать исправление.
8. **Завершить урок** отзывает оба доступа на сервере. Открытая игра узнает об этом при следующем успешном опросе и отменяет незавершённые команды преподавателя.

Игра ученика должна находиться на первом уровне. Если сохранён второй уровень, панель показывает его, но управление отключено. Автоматического сброса прогресса нет. Ученик может использовать обычную кнопку начала заново по своему решению.

## Исправление остановки синхронизации

Исправлен браузерный вызов таймеров: повторный опрос мог прекращаться после первого сообщения с ошибкой `Illegal invocation`, оставляя у ученика устаревшую надпись «Подключено». Теперь таймеры вызываются без привязки к объекту учебного подключения. Добавлены проверки браузерных ограничений таймера и полного автоматического цикла опроса с реальным HTTP-сервером и игровым ActionController.

Если оба локальных сервера уже запущены из этой папки, обновите страницы ученика и преподавателя через Ctrl+F5. Перезапуск серверов для этого исправления не требуется. Сохранённый доступ восстанавливается; после обновления подождите до 10 секунд, если прежняя аренда вкладки ещё не освобождена. Если часовой срок урока уже истёк, создайте новый урок.

## Локальный запуск

Нужен Node.js 24. В двух отдельных терминалах из папки `korean-stickman`:

```powershell
npm run dev
```

```powershell
npm run teacher:server
```

Игра: `http://localhost:5173/`. Панель: `http://localhost:5173/teacher.html`. Сервис комнат: `http://localhost:8081/health`.

Если старая игра уже запущена, перезапустите её из обновлённой папки. Откройте панель в одном браузере, а скопированную ссылку ученика — в другом, на том же компьютере. Не открывайте две роли в одной вкладке.

`localhost` в приглашении работает только на этом компьютере. Для проверки на двух устройствах нужны публичные HTTPS-адреса, описанные ниже.

## Публичная проверка: отдельный сервис комнат

Схема: **GitHub Pages (игра и панель) ↔ отдельный Node.js-сервис комнат**. Обычная цепочка STT остаётся прежней и независимой.

Создайте отдельное приложение с одним постоянно работающим Node.js-процессом. Загрузите исходный репозиторий целиком: сервис использует общий `src/catalog.js`. Не заменяйте существующие Render, Netlify, Vercel или Amvera STT-приложения.

Параметры приложения:

- Node.js: `24.x`.
- Корневая папка: корень проекта, где находится `package.json`.
- Установка/Build Command: `npm ci`.
- Start Command: `npm run teacher:server`.
- `NODE_ENV=production`.
- `FRONTEND_ORIGINS=https://averanges.github.io` — без `/korean-stickman/` и завершающего слеша.
- `PORT` — порт от платформы; по умолчанию `8081`, прослушивание `0.0.0.0`.
- Публичный HTTPS-домен с проксированием на этот порт.
- Healthcheck: `/health` (ожидается `ok: true`, `service: teacher-mode`).

Ни `GROQ_API_KEY`, ни другие STT/LLM-ключи этому сервису не нужны. Не переносите в него локальный `.env` игры. Не используйте Vercel Functions или несколько экземпляров: временные комнаты находятся в памяти одного процесса. Перезапуск или засыпание с потерей процесса завершает уроки; для устойчивой удалённой проверки нужен процесс, живущий весь урок. История после завершения/истечения не сохраняется.

В GitHub откройте **Settings → Secrets and variables → Actions → Variables**. Добавьте публичную Repository variable `TEACHER_API_BASE_URL`: фактический HTTPS-адрес нового сервиса, без путей и токенов. Затем запустите существующий workflow **Publish frontend to GitHub Pages**. Это адрес, а не секрет. Остальные переменные STT менять не требуется.

После публикации панель будет по адресу `https://averanges.github.io/korean-stickman/teacher.html`. При пустом `TEACHER_API_BASE_URL` опубликованная игра продолжает работать, а Teacher Mode сообщает, что сервис уроков не настроен. Адрес публичного сервиса пока не задан.

## Безопасность и восстановление

- Урок живёт один час. Токены преподавателя, приглашения и авторизованного ученика независимы, генерируются криптографически; на сервере хранятся только их хеши.
- Приглашение связывается с одним учеником. Повторный запрос того же ученика после потери ответа безопасен; другое устройство не получает доступ по уже использованному приглашению.
- Авторизация передаётся в заголовке, приглашение — в теле запроса. Ссылочные токены находятся во фрагменте `#`, который не отправляется HTTP-серверу; аналитика и логирование токенов не добавлены.
- Активная вкладка защищена Web Locks и серверной арендой на 8 секунд. Обновление восстанавливает доступ; если уведомление об уходе потеряно, восстановление может занять около 8 секунд. Современный браузер, HTTPS и разрешённое временное хранилище обязательны.
- Опрос раз в 1,5 секунды включается только после открытия/восстановления урока. При сетевом сбое связь восстанавливается автоматически. Через 8 секунд без сообщений ученик считается офлайн.
- Если закрыть вкладку целиком, её временный доступ может исчезнуть. Скопированная заранее защищённая ссылка сохраняет возможность входа преподавателя. Закрывшему свою вкладку ученику может понадобиться новый урок; одноразовое приглашение намеренно не открывается другому устройству.
- Команды имеют уникальные ID. Журнал ученика предотвращает повторное действие. После обновления посреди анимации результат отмечается неизвестным, а команда не запускается заново. Тайм-аут команды — 60 секунд; движок ожидается не более 55 секунд.
- Закрытие отзывает права немедленно на сервере. Уже выполняющееся локальное действие может продолжаться до доставки уведомления об отзыве; это не мгновенная синхронизация графики.
- Сервер принимает только разрешённые поля/маршруты, JSON до 32 КиБ, проверяет роль, Origin и срок урока. Есть ограничения частоты запросов и очереди. CORS не заменяет проверку токена.
- Передаются только текущие характеристики и ограниченный набор текстовых технических событий. Аудиозаписи, экран и весь игровой мир в сервис комнат не отправляются. Буфер событий ограничен и удаляется вместе с комнатой.

## Проверки и статус приёмки

Прошёл полный набор из 335 автоматических теста; сборки Pages и backend завершены успешно. Автоматически проверены: разные роли и одноразовый доступ; аренда вкладки; истечение и закрытие; CORS, размер и частота; подтверждение через настоящий ActionController после анимации; повторная доставка; обновление страницы и потеря подтверждения; отключение/восстановление транспорта; работа управления после ошибки STT; подавление запоздалого STT при исправлении; закрытие в момент выполнения. В сетевых тестах используются два независимых HTTP-клиента, а не два браузера.

В интерфейсе проверены открытие панели, создание урока и копирование приглашения. Полный сценарий преподаватель + ученик в двух браузерах не завершён: инструмент управления остановился, потому что не смог надёжно определить URL окна Chrome. Реальный голос ученика в удалённом уроке также ещё не проверен. Успешные HTTP-тесты не подменяют эту приёмку.

Перед использованием с учениками выполните:

1. Откройте панель в одном браузере, создайте урок, откройте ссылку ученика в другом.
2. Убедитесь, что появился статус «Онлайн», а ссылка ученика очистилась от приглашения.
3. Поставьте национальность «Россия». Дождитесь изменения героя и статуса «Выполнено» после анимации. Проверьте профессию, пол и приветствие.
4. Произнесите обычную фразу. Проверьте события записи/отправки, имя STT-сервера, транскрипцию, интерпретацию и последнюю команду.
5. При ошибке STT проверьте, что ручная команда преподавателя по-прежнему работает.
6. Во время ожидания STT отметьте исправление и задайте другую характеристику. Поздний ответ не должен отменить исправление.
7. Отключите сеть ученика: преподаватель должен увидеть офлайн. Верните сеть — связь должна восстановиться без повторного действия.
8. Обновите игру ученика. Проверьте восстановление без нового приглашения и без повтора уже выполненной команды.
9. Попробуйте ту же ссылку на другом устройстве и дублированную вкладку: активный ученик не должен быть незаметно заменён.
10. Завершите урок: новые команды и старые ссылки должны потерять доступ. На втором уровне команды должны отклоняться.

До подтверждения этой проверки функциональность второго уровня не расширяется.
