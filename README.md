# Korean Stickman — «Создай своего героя» + «Мой дом»

Добавлен второй уровень: технический прототип псевдо-2.5D с тремя предметами, обходом стола, чтением и питьём воды. Вход через «В мир»; возврат — «К герою». [Команды, устройство и проверки уровня 2](docs/HOME.md). [Короткая демонстрация](docs/home-demo.gif).

Публикация разделена: **GitHub Pages — интерфейс, Render — голосовой API**.
[Пошаговая инструкция с вашими адресами](docs/RENDER.md).
Pages: https://averanges.github.io/korean-stickman/ · API: https://korean-stickman.onrender.com/api/stt
Локально по-прежнему `npm run dev`; на Render — `npm start`. Сама публикация не выполнялась.

Текущее обновление: интерпретация смысла ответа, формальное 입니다, подлежащие и выбранное имя героя. Диагностика и ограничения: [docs/INTERPRETATION.md](docs/INTERPRETATION.md). Промежуточные субтитры пока не подключены.

Первый уровень «Создай своего героя»: корейские фразы меняют персонажа.
В V1.2 голос управляется двумя нажатиями, а не паузами в речи.

## Запуск и настройка голоса

Нужен Node.js 24.x. Зависимостей нет.

```sh
npm install
npm run dev
```

Откройте **http://localhost:5173**. При обновлении с V1.1 сначала остановите старый сервер через Ctrl+C:
старая версия сервера не содержит нового голосового API.

Для голоса нужен ключ [Groq](https://console.groq.com/keys).
Если файла `.env` ещё нет, скопируйте `.env.example` в `.env` рядом с `server.mjs`.
Вставьте ключ после `GROQ_API_KEY=` и сохраните файл. Строку `STT_MODEL=whisper-large-v3` можно оставить без изменений.
Сервер перечитывает конфигурацию перед запросами; после изменения ключа перезапуск не требуется.
Ключ нельзя помещать в `src/`, вводить на странице игры или передавать через параметры URL.
Сервер блокирует выдачу `.env` и серверных модулей; `.env` исключён из Git и поставочного архива.

Без ключа весь ручной ввод и создание героя работают; сервер объяснит, что для распознавания требуется настройка.

## Как записывать

1. Нажмите микрофон один раз и разрешите доступ к нему.
2. Говорите в своём темпе, в том числе с длинными паузами. Запись идёт непрерывно.
3. Закончив фразу, нажмите микрофон второй раз. Только теперь полный аудиофайл отправляется на распознавание.
4. «Отменить запись» удаляет текущую попытку без отправки. Во время обработки эта кнопка отменяет ожидание результата.

Удерживать кнопку не нужно. Состояния: «Готов», «Слушаю», «Обрабатываю», «Повторить».
При записи отображается таймер. Тишина не запускает отправку и не вырезается из файла.
Нет фонового Web Speech API или автоматического переключения на него.
Если браузер/устройство самостоятельно прерывает запись, её обрывок не отправляется.

Слишком короткая запись (менее 0,5 с), запись без обнаруженного звука речи и пустой файл не отправляются.
Проверка энергии аудио используется только после ручного завершения; она не приостанавливает запись.
При достижении 20 МБ запись отменяется с сообщением, а не отправляется автоматически.
Блокировка экрана, отключение микрофона и политики браузера могут прервать захват — в этом случае потребуется новая попытка.

Для микрофона нужен localhost или HTTPS. Формат выбирается через `MediaRecorder.isTypeSupported`:
WebM/Opus, Ogg/Opus или MP4, в зависимости от браузера.
Сервер передаёт Groq исходный файл без нарезки, удаления пауз и словарного prompt.
Само приложение не сохраняет аудио на диск.

## Предложения и герой

`안녕하세요` или `안녕` будят героя. Можно сразу назвать характеристику: герой проснётся автоматически.

- Пол: `여자예요`, `남자예요`.
- Страны: `중국 사람이에요`, `한국 사람이에요`, `미국 사람이에요`, `일본 사람이에요`,
  `독일 사람이에요`, `프랑스 사람이에요`, `러시아 사람이에요`, `영국 사람이에요`.
- Профессии: `선생님이에요`, `학생이에요`, `의사예요`, `회사원이에요`, `가수예요`,
  `군인이에요`, `요리사예요`, `기자예요`.

Поддерживаются варианты с `저는` и `이 사람은`, пробелы и конечная пунктуация.
Для ручного тестирования также принимаются известные существительные без связки, например `의사`.
**В голосовом режиме незаконченные фразы и голые существительные не дополняются и не применяются.**

В голосе допускаются известные варианты произнесения связки (`에요` вместо `예요/이에요`) и точные соседние повторы.
Разные характеристики, отрицания и сложные исправления не угадываются: игра нейтрально просит повторить.
Промежуточных результатов нет. Сомнительный ответ STT не меняет профиль и не запускает повторное пробуждение.
Показатели качества Whisper используются как эвристика; они не оценивают произношение ученика.

Имя необязательно и задаётся вручную. Пол, страна и профессия меняются независимо.
Команды выполняются последовательно; во время анимации разрешена очередь до шести ожидающих фраз.
«В мир» доступно с любым заполнением анкеты и открывает второй уровень «Мой дом».
Профиль хранится в `localStorage` этого браузера под ключом `korean-stickman.hero.v2`.
При ошибке голоса профиль сохраняется. «Начать заново» очищает героя и отменяет незавершённые действия.

## Графика

Все ассеты — оригинальные SVG: стул, коробка, восемь аксессуаров стран, восемь предметов профессий,
восемь упрощённых флагов и два варианта причёски. [Каталог](docs/assets.svg).
Условные головные уборы — игровые мотивы, а не описание повседневной одежды жителей стран.

В V1.2 уточнены положение таза на сиденье, колени, стопы и корни ног; туловище и руки укорочены.
Длина туловища сохраняется при интерполяции поз. Пробуждение и вставание остаются плавными.
Надпись возле стула удалена. Стиль, анкета, цветные рисунки стула/коробки и длительности взаимодействий сохранены.
Масштабы, точки крепления и слои коробки из V1.1 сохранены с необходимой адаптацией к новым позам.

## Архитектура

- `src/speech.js` — MediaRecorder, ручное завершение/отмена, проверка пустого аудио, освобождение микрофона.
- `src/stt-client.js` — заменяемый HTTP-адаптер распознавания.
- `server.mjs` — на Render только API с CORS; локально также публичные файлы, без выдачи конфигурации.
- `src/api-config.js` — адрес API: локально относительный, в Pages-сборке публичный Render.
- `scripts/build-pages.mjs` — сборка только публичных файлов в `dist/`.
- `.github/workflows/pages.yml` — ручная публикация `dist/` в Pages через GitHub Actions.
- `server/config.mjs` — чтение серверного `.env` без передачи ключа клиенту.
- `server/stt.mjs` — заменяемый провайдер Groq Whisper, проверка метаданных и обработка ошибок.
- `src/parser.js` — rule-based parser, отдельные правила для полного голосового результата.
- `src/catalog.js`, `world.js`, `controller.js` — словарь, профиль/сохранение и последовательная очередь.
- `src/geometry.js`, `renderer.js`, `assets.js` — суставы, интерполяция, крепления и SVG-графика.

Для замены провайдера достаточно реализовать серверный `transcribe(bytes, mime, {signal})`;
для замены транспорта — клиентский `transcribe(blob, {durationMs, signal})`.
