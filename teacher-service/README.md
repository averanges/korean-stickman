# Сервис комнат Teacher Mode 0.3 — отдельный прототип

При локальной разработке команда `npm run dev` запускает интерфейс и API уроков на **5175**. Для отдельного сервиса используйте инструкцию ниже. [TEACHER03-START.md](../TEACHER03-START.md)

Отдельный Node.js HTTP-сервис. Запускается из **корня всего проекта**, а не из этой папки:

```powershell
npm run teacher:server
```

Проверка отдельного процесса на компьютере: `http://localhost:8083/health`.

Параметры: `PORT` (по умолчанию 8083), `NODE_ENV=production`, `FRONTEND_ORIGINS=https://averanges.github.io`. Продакшен: один Node.js 24 процесс за HTTPS-прокси. STT-ключи и база не требуются. Данные только в памяти, TTL комнаты 1 час. Перезапуск удаляет комнаты.

[Быстрый пульт 0.2 и обновление](../docs/TEACHER-MODE-0.2.md).

Первичная настройка, публикация отдельного сервиса, GitHub Actions и незавершённая проверка в двух браузерах: [инструкция](../docs/TEACHER-MODE-0.1.md).

Публичный GET `/health` сообщает только готовность самого процесса. Все действия урока — POST `/teacher-api/rooms` и `/teacher-api/rooms/{roomId}/{action}` с точным Origin, проверкой роли/токена, срока действия и частоты. Нет доступа к аудио, STT, файлам или экрану. Не включайте логирование тел запросов/Authorization на внешнем прокси.
